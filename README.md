# ForgeFit (beta)

Built web version of ForgeFit, published with GitHub Pages:
https://13guptasudhanshu-maker.github.io/forgefit/

Private beta — the app asks for an access code. This repository holds only the built app (no source, no keys).

On iPhone: open the link in Safari → Share → Add to Home Screen → open ForgeFit from the home screen → request access.
